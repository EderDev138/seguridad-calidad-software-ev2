El paciente con RUT 12345678-5 ya existe en el ambiente.

POST /pacientes con rut="12345678-5"    ->  HTTP 409 (esperado 409)
POST /pacientes con rut="12.345.678-5"  ->  HTTP 409 (esperado 409)

El segundo caso es el mismo RUT escrito con puntos. Si el sistema
respondiera 201, la restriccion de unicidad se podria evadir solo
cambiando el formato de entrada.
